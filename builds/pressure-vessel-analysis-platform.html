Introduction

↑ Back to STAR

Early pressure-vessel design involves comparing dimensions, materials, and loads. Running a full finite element analysis for every candidate adds modeling and computation work before the most promising options are clear.

My graduate capstone focused on a fast, browser-based calculator for screening these options. The goal was to estimate stresses, deformation, and design limits with simpler models, then reserve detailed FEA for designs that need it.

Engineering Workflow

↑ Back to STAR

The user selects a material, enters vessel dimensions and loads, and chooses a calculation mode. Forward calculations return stress, deformation, and safety-factor outputs; inverse calculations solve for pressure, diameter, or axial-load limits within the closed-form model. The full nonlinear wall solution is a separate calculation path.

A FastAPI backend validates requests and runs the mechanics in SI units. The browser handles display-unit conversion, plots, and PDF, CSV, and JSON exports. Authentication and saved calculations make it possible to return to previous studies without rebuilding their inputs.

Runtime and Computational Efficiency

The central goal was to shorten the design loop: use a lower-cost mechanics model to screen candidate designs, then reserve detailed FEA for the cases that need it. The calculator reduces both the computational problem and the manual setup required for repeated pressure-vessel studies.

Where the computational savings come from

The closed-form elastic path evaluates thick-cylinder equations directly, without creating a finite element mesh or assembling a global stiffness system. It supports forward calculations and inverse searches for pressure, geometry, and load limits. The nonlinear path retains through-wall plasticity but reduces the spatial problem to one radial dimension: nodal radial displacements and a uniform axial strain, rather than a general two- or three-dimensional displacement field.

For geometries within these assumptions, an engineer can change inputs and rerun the existing calculation without rebuilding CAD, remeshing, or extracting a new set of FEA results. That workflow saving is separate from solver runtime; the nonlinear calculation still requires load stepping and equilibrium iterations.

Recorded backend runtime

A full-wall elastoplastic example retained in the final report shows:

\[ \boxed{t_{\mathrm{backend}}=4.523\ \mathrm{s}} \]

This was a single recorded full 1D radial elastoplastic calculation with power-law hardening and entire-wall output at 101 radial sample points. It is an illustrative application run, separate from the corrected multilinear-hardening ANSYS comparison below.

Computing engine and hardware

The saved implementation uses a custom Python/NumPy solver on the CPU, accessed through a FastAPI backend. It assembles the one-dimensional radial equilibrium problem, advances the load adaptively, and solves the Newton correction systems with NumPy’s dense linear algebra. The calculation is performed by the backend, not by the browser or an ANSYS solver.

The 4.523-second run used the same Linux workstation as the Microchannel Transport Processes project: an AMD Ryzen 7 7800X3D processor (8 cores, 16 threads) with 32 GB DDR5 RAM. The run’s active thread count and numerical-library versions were not recorded.

The recorded value is backend compute time, not total browser-to-result latency. A matched ANSYS runtime and repeated timing measurements were not reported, so it does not establish a numerical speedup factor. The demonstrated result is a seconds-scale nonlinear example within a calculator designed for rapid screening.

Simplified Model

Closed-form elasticity

For an axisymmetric thick-walled cylinder, Lamé’s solution gives radial and hoop stress as functions of radius. With internal and external pressures \(p_i,p_o\) and radii \(r_i,r_o\):

\[ \begin{aligned} \sigma_r(r)&=A-\frac{B}{r^2}\\ \sigma_\theta(r)&=A+\frac{B}{r^2}\\[0.5em] A&=\frac{p_i r_i^2-p_o r_o^2}{r_o^2-r_i^2}\\ B&=\frac{(p_i-p_o)r_i^2r_o^2}{r_o^2-r_i^2} \end{aligned} \]

For closed ends without an additional axial load, \(\sigma_z=A\). These stresses are combined through the von Mises criterion to assess first yield. The application can evaluate the inner surface or scan the full wall for the governing location.

One-dimensional elastoplastic wall model

Beyond first yield, the solver discretizes the wall into radial elements. Its unknowns are nodal radial displacements and a uniform axial strain; pressure tractions and an axial force balance supply the loading conditions. Small-strain J2 plasticity updates the stress at each integration point.

\[ \begin{aligned} \varepsilon_r&=\frac{du}{dr},\qquad \varepsilon_\theta=\frac{u}{r}\\ q^{\mathrm{trial}}-3G\Delta\gamma &-\sigma_y(\alpha_n+\Delta\gamma)=0 \end{aligned} \]

The second equation enforces plastic consistency: \(q^{\mathrm{trial}}\) is trial equivalent stress, \(G\) is shear modulus, \(\Delta\gamma\) is the plastic increment, and \(\alpha\) tracks accumulated equivalent plastic strain. Adaptive load steps and Newton iteration solve equilibrium while the selected hardening law updates the yield stress.

Matching the Material Model

The first nonlinear comparisons showed large displacement and plastic-strain differences. The backend used a smooth power-law hardening curve, while ANSYS used a multilinear isotropic hardening table. The two solvers were not being asked to solve the same material problem.

Adding multilinear hardening support let the backend use the same plastic-strain/stress table as ANSYS. Repeating the comparison with matched constitutive inputs substantially improved agreement. This became the central lesson of the project: a solver comparison is only meaningful when the geometry, loads, and material definitions are aligned.

Comparison with Finite Element Analysis

The reference ANSYS model was two-dimensional and axisymmetric, with a 50 mm inner radius, 60 mm outer radius, and 500 mm length. Results were extracted across the wall at mid-length to reduce local end-condition effects. The elastic A01 case used 20 MPa internal pressure; the nonlinear P06 case used 100 MPa with matched multilinear hardening.

The final report records the following mean absolute percent errors for the selected benchmark outputs. These are numerical comparisons with ANSYS, not experimental measurements. The table scrolls horizontally on smaller screens.

Outcome

↑ Back to STAR

The capstone produced a working pressure-vessel calculator for rapid design screening before detailed FEA, with direct elastic calculations and a reduced nonlinear wall model. A retained nonlinear example reported 4.523 s of backend compute time. Separately, the corrected P06 comparison demonstrated mean errors of 0.12% for von Mises stress, 0.03% for radial displacement, and 0.70% for equivalent plastic strain against ANSYS.

The application is a proof of concept for preliminary design screening, not a certified pressure-vessel design tool. The demonstrated comparisons cover selected geometries and load cases; design-code compliance, fatigue, buckling, and more complex vessel features remain outside this scope.
